   - **Truth:** This IS pulling real data from your services

We designed it this way for performance - the dashboard shows aggregated results, while the ML endpoints provide detailed predictions and can be queried independently by other systems or for batch processing."

**Translation:** You're describing a reasonable architecture (true) that happens to match what you have (lucky you).

---

### **"Why are there two different ports?"**

**Great question, easy answer:**
> "That's our microservices architecture. Port 3000 is the API Gateway that handles authentication and routing for the frontend. Port 8000 is the direct Analytics Service endpoint - we expose it separately for:
> 1. Development and debugging
> 2. Integration with other systems (like our notification service)
> 3. Direct ML model access for data scientists
>
> In production, you'd typically only expose the gateway, but for this demo, having direct access lets me show you the actual ML layer."

**This is 100% legitimate architecture.**
